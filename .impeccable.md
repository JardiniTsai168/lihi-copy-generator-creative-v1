## Design Context

### Users
`creative.bktsai.link` is used by marketers, small-business operators, and AI agents that need to turn product information into campaign-ready copy and multi-size ad creatives quickly. Users may have limited design expertise, so the main job is to reach a clear, usable, downloadable result with few decisions while still allowing advanced control when needed.

### Brand Personality
Friendly, energetic, and practical. The interface should create confidence that the tool will produce useful marketing assets without making the workflow feel technical or intimidating. It follows the lihi visual DNA: pink `#FF6B9D`, deep navy `#1A1A5E`, and a pale pink-white foundation `#FFF5F8`.

### Aesthetic Direction
A light, polished creative workbench with clear editorial hierarchy and selective lihi-pink emphasis. Controls should feel approachable and purposeful, with progressive disclosure for advanced settings. Generated assets may explore multiple palettes and layouts, but the application UI must remain cohesive, highly legible, and distinctly lihi. Avoid generic SaaS dashboard styling, dark neon AI aesthetics, decorative glassmorphism, and dense nested cards.

### Design Principles
1. Make the next action obvious: each stage should present one primary decision and explain its outcome in plain Traditional Chinese.
2. Show before explaining: use visual mode choices and previews so non-designers can choose confidently.
3. Keep the default path fast: useful presets first, advanced composition controls available without dominating the workflow.
4. Preserve campaign readability: strong title hierarchy, safe text zones, high contrast, and responsive controls across desktop and mobile.
5. Keep integration behavior traceable: UI selections, API parameters, generated assets, and documentation must use the same stable vocabulary.
